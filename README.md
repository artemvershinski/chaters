## 🌟 **ВСЕЛЕННАЯ CHATERS**

**Chaters** — это минималистичный, молниеносный и полностью приватный мессенджер, созданный для тех, кто ценит **чистоту кода** и **абсолютную свободу общения**.

> *Никакой цензуры. Никаких алгоритмов. Только ты и твой космос.*

<br>

<div align="center">
  
| 🚀 **FEATURE** | 📡 **DESCRIPTION** |
|----------------|-------------------|
| **Мгновенные сообщения** | WebSocket реального времени |
| **Голосовые сообщения** | Запись по зажатию, как в Telegram |
| **Файлы и медиа** | Изображения, аудио, документы |
| **Групповые чаты** | Уникальный ID — #космос |
| **TTL сообщений** | Автоудаление через N дней |
| **PWA** | Работает как приложение |
| **Render Cloud** | Бесплатный хостинг 24/7 |

</div>

## 🚀 **БЫСТРЫЙ СТАРТ**

```bash
# Клонируй вселенную
git clone https://github.com/artemvershinski/chaters.git

# Войди в космос
cd chaters/backend

# Установи зависимости
npm install

# Запусти двигатели
npm start

# Открой портал
http://localhost:3000
```

## 🌍 **ДЕПЛОЙ НА RENDER**

**Один клик — и ты на орбите:**

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/artemvershinski/chaters)

```yaml
# render.yaml — инфраструктура как код
services:
  - type: web
    name: chaters
    env: node
    rootDir: backend
    buildCommand: npm install
    startCommand: npm start
    envVars:
      - key: JWT_SECRET
        generateValue: true
```
